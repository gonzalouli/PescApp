# PescApp
Repositorio para el frontend de PescApp con Ionic-React

Para instalar la app nos dirigiremos al directorio raiz y ejecutaremos:  
`npm i`  
Esto instalara todas las dependencias.  
Para realizar una instalacion multiplataforma con Capacitor realizaremos los siguientes scripts:  
`ionic integrations enable capacitor`  
`ionic capacitor add android`  
`ionic capacitor add ios`  
`ionis cap sync`  
  *Para realizar las acciones anteriores debemos tener AndroidStudio instalado y en el path de nuestra computadora o Xcode y emulador de iOs.
